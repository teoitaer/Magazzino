☁ Collegamento iniziale

L'archivio è già configurato su teoitaer/Officina. Per abilitare il salvataggio automatico su questo dispositivo, inserisci una sola volta un token GitHub fine-grained, con accesso al solo repository Officina e permesso Contents: Read and write. L'app lo conserva localmente per riutilizzarlo alle aperture successive. Usalo solo su dispositivi personali e protetti: chi accede a questo browser potrebbe recuperare il token.
Il repository è pubblico: le schede e le foto salvate nel JSON sono leggibili da chiunque. Un token di scrittura non deve mai essere inserito nel codice pubblicato. L'accesso si configura una sola volta per ogni browser/dispositivo e potrebbe richiedere una nuova configurazione se il token scade, viene revocato o cancelli i dati del browser. Per una configurazione zero-touch su tutti i dispositivi serve un servizio di autenticazione/backend.
